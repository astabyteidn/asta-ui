# Deprecated

The Go + htmx templ port of Astabyte UI was dropped in 0.9.0. `go/v0.8.0` stays available but gets no updates.

Use the HTML + CSS layer instead. It works from Go `html/template` and htmx with the same look: link `asta.css` and `asta.js`, then use the `asta-*` classes. Guide: https://ui.astabyte.com/css
