# Getting help

Stuck? Start here.

1. **Read the docs.** [ui.astabyte.com](https://ui.astabyte.com) has every component with a live demo, the code, and the props. [Installation](https://ui.astabyte.com/installation) covers setup.
2. **Search the issues.** Someone may have asked already: [open and closed issues](https://github.com/astabyteidn/asta-ui/issues?q=is%3Aissue).
3. **Open an issue.** Found a bug? Use the [bug report](https://github.com/astabyteidn/asta-ui/issues/new?template=bug_report.yml). Want something new? Use the [feature request](https://github.com/astabyteidn/asta-ui/issues/new?template=feature_request.yml).

Security problems go through [SECURITY.md](SECURITY.md), never a public issue.

Need help building a product with it? Astabyte is a studio, and you can [hire us](https://astabyte.com/contact).
