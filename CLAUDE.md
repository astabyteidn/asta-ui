# CLAUDE.md — asta-ui

Source of **ui.astabyte.com**: a component kit and a motion lab, shipped as a shadcn registry and as the `asta-ui` npm package (CLI + library). Public repo, MIT. Split out of the private `astabyte` monorepo on 2026-11-17.

## Before you finish

```sh
bunx tsc --noEmit && bun run lint && bun run skill && bun run base --check && bun run perf && bun run build
```

## Rules

**Generated files.** After adding or renaming a component or changing a description, run `bun run skill`. After editing a Radix component that has a generated Base twin, run `bun run base`. CI fails on a stale diff.

**Kit files.** Tokens only (`paper`, `ink`, `mute`, `signal`, `brand`), never hard-coded colours. Local `cx`. They may import other kit files. Don't write `asChild` as a literal: Base UI projects rewrite it.

**Motion lab.** Real use cases (trading, payments, ecommerce) that look like finished product UI and fill the card. One focused, looping motion moment per card. Fake data and brands only.

**Motion.** Transform and opacity only. One easing, `cubic-bezier(.16,1,.3,1)`, or springs. Loops fade out instead of snapping. Respect reduced motion. Keyframes go in `<style href="asta-<name>" precedence="asta">` so React hoists them once. A bare `<style>` inside a popup recalculates the whole page on open.

**Performance.** Every component must stay smooth on a mid-range phone. `bun run perf` (`scripts/perf-check.ts`) enforces the static part and runs in CI. Errors fail the build, warnings are for review.
- Animate `transform` and `opacity` only. `@keyframes` that change width, height, top, left, margin or padding are errors. Layout transitions are warnings; mark a deliberate one (an accordion panel, an auto-grow field) with a `perf-ok` comment.
- Loops (`requestAnimationFrame`, `setInterval`) pause when the element is offscreen (IntersectionObserver) or the tab is hidden, and stop on unmount. Every listener, observer and interval is cleaned up.
- No layout reads (`getBoundingClientRect`, `offsetWidth`) inside per-frame callbacks. Measure once, or on resize.
- Keyframes go in `<style href precedence="asta">`, never a bare `<style>`.
- Images are webp, sized (`width`/`height`) and `loading="lazy"`. Long lists (100+ items) render in chunks or with `content-visibility`.
- No new runtime dependencies for a component. Budgets: a component file 28 KB, a demo 14 KB.
- Pages: previews mount only near the viewport and keep their height when unmounted (`components/ui-site/Live.tsx`), so scrolling never jumps.

**Look.**
- White ground, black and white, one blue (`brand` #2f54eb). No lime, green, red or gold. Market up = blue, down = neutral.
- Slight rounding: buttons 6–9px, cards 10–14px. Pills only for switches, avatars and dots.
- Header is sticky, 56px. Once the page scrolls a solid paper bar fades in (no glass/blur, no gradient tail, no drop shadow, no bottom border). Docs sidebars stick at `top-14`. The docs shell is centred at 1600px (`.px-shell`).
- Placeholder photos come from Unsplash, self-hosted in `public/lab/`, neutral and unbranded.
- Never name or show real web3 projects.

**Docs copy.** Write it like a blog post, not a spec. Short sentences, one idea each. Lead with what the reader does. Put a TL;DR or list where it helps. No semicolons or long parentheses. Don't wrap inline `<code>` in brackets: it renders as `( code )`.

## Releases

Tags deploy. `main` does not.

`main` is protected, admins included: every change goes through a PR, the `check` job must pass, squash merge only, linear history, no force push. Branch, push, `gh pr create`, wait for `check`, `gh pr merge --squash`.

1. Bump `version` in `package.json` **and** `packages/asta-ui/package.json`.
2. Add a `CHANGELOG.md` entry, open a PR and merge it.
3. On the merged `main`: `git tag vX.Y.Z && git push origin vX.Y.Z`

`.github/workflows/deploy.yml` then:
- **check:** versions match the tag, then builds and runs `npm pack --dry-run`
- **deploy:** pushes the image `asta-ui:<version>` to our registry, calls the Portainer webhook with `?tag=<version>`, waits for `https://ui.astabyte.com/healthz`
- **publish-cli:** `npm publish --provenance` (skipped if that version already exists)

Rollback means calling the webhook with an older tag. Production is a single Docker service behind nginx.

Commits: English, one line, Conventional Commits, no body, no trailers.

Pageviews go to the Astabyte API (`POST /api/analytics/collect`, routed by nginx), with a `/ui` prefix.
